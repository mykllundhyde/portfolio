# Michael Apochi — Portfolio

A responsive, static portfolio website built with plain HTML, CSS and JavaScript. No build step or framework required.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public repository named `michael-portfolio`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site will be published at `https://YOUR-USERNAME.github.io/michael-portfolio/`.

GitHub Pages publishes static HTML/CSS/JS directly from a repository. See https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Before launch — personalise these details
- Replace the illustrative project artwork in `index.html` / `styles.css` with your real project images and case-study links.
- Update the email address `hello@michaelapochi.com` to your preferred contact email.
- Replace the generic social profile URLs with your actual LinkedIn, Instagram, Behance and X links.
- Review the experience dates and wording.
- Add a portrait or project imagery in `assets/` if desired.

The project tiles are original CSS-built placeholders, not copies of your Framer project artwork. The Framer URL could not be retrieved for a source-accurate migration in this session.
